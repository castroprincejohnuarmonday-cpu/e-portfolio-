What I have learned

Throughout our lessons in CC102 – Fundamentals of Programming, I have learned many important concepts about programming and Java. At first, I thought programming was mainly about writing code, but I learned that there is a proper process that programmers need to follow before they can create a working program. I learned about problem definition, problem analysis, algorithm development, coding, and debugging. I also learned that algorithms are step-by-step procedures used to solve problems, while pseudocode helps programmers describe an algorithm in a simple way before writing actual code.

I also learned how flowcharts can help in planning a program. Different symbols are used to represent different processes, inputs and outputs, decisions, and the beginning or ending of a program. I learned that decision structures allow a program to choose what action to perform depending on whether a condition is true or false. Logical operators and relational operators are also important because they help a program evaluate conditions and make decisions.

Another important lesson I learned was the introduction to Java programming. I learned that Java is a programming language and that a Java program is made up of classes, methods, and statements. I learned about the main method, which is important when executing a Java application. I also learned about the Java program cycle, where source code is compiled into bytecode and then executed.

In programming basics, I learned about keywords, identifiers, variables, and data types. Variables are used to store values, while data types determine what kind of values can be stored. I learned that Java has primitive data types such as boolean, byte, char, short, int, long, float, and double. I also learned that Java is case-sensitive, so uppercase and lowercase letters can have different meanings.

The lessons about Java operators also helped me understand how programs perform calculations and comparisons. I learned about arithmetic operators, assignment operators, relational operators, and logical operators. I also learned about operator precedence, which determines the order in which operations are performed. This showed me that even simple expressions need to be written and evaluated carefully.

I also learned about conditional statements such as if, if-else, else-if, and switch. These statements allow a program to make decisions based on conditions. After that, I learned about iteration statements, including while loops, do-while loops, and for loops. These allow a program to repeat certain instructions. I also learned about branching statements such as break, continue, and return, which can change the flow of a program.

Overall, these lessons helped me understand that programming is not only about memorizing codes and syntax. It is about learning how to think logically, analyze problems, create solutions, and turn those solutions into programs. I still have many things to learn about programming, but these lessons gave me a better foundation in Java and helped me understand how programmers develop solutions step by step. I believe that what I have learned in these lessons will help me improve my programming skills and become more confident in creating programs in the future.
